# Coordination Modülü

Öğretmen ziyaret programı, departman dağılımı, rapor ve evrak takibi.

:::warning Diyagramlar KAVRAMSAL — kodun bugünkü hâli değildir

Bu sayfadaki sınıf/sıra diyagramları modülün ilk tasarımını gösterir ve koddan **üretilmez**;
sapmayı yakalayan bir test de yoktur. Bilinen farklar:

- **API katmanı ASP.NET Minimal API'dir** (`MapGet`/`MapPost` → `bus.InvokeAsync`).
  `[WolverinePost]`/`[WolverineGet]` attribute'leri kodun **hiçbir yerinde kullanılmaz**;
  diyagramlardaki `POST`/`GET` etiketleri yalnız HTTP fiilini gösterir.
- **Enum'lar SmartEnum'dur** (`Name` İngilizce = serialize, `Slug` Türkçe = arayüz).
  Diyagramlardaki `MAZERETLI`, `ONAY_BEKLIYOR` gibi büyük harfli Türkçe değerler kodda
  bulunmaz.
- **Denetim aktörleri kimlik taşır, ad değil** (#139): `MarkedBy` → `MarkedById` (`Guid`).
  Ad okuma anında `UserNameView`'dan çözülür.
- Kiracı damgası, kapsam guard'ları ve onay zincirlerinin bugünkü hâli diyagramlarda yoktur.

Bir davranışın **bugünkü** kuralı için sırasıyla: `CLAUDE.md` → ilgili ADR →
[İş Kuralları](../architecture/business-rules.md) / [İzin Matrisi](../actors/permissions.md) →
kilitleyen test.
:::

## Sequence Diagrams

### Ziyaret Tamamla (CompleteVisit)

```plantuml
@startuml CVRSequenceDiagram
autonumber

actor "Koordinatör Öğretmen" as Teacher
participant "Web UI" as UI
participant "MESNET.Coordination.Api\nCoordinationEndpoints" as API
participant "MESNET.Coordination.Application\nCompleteVisitHandler" as Handler #LightBlue
participant "Marten\nIEventStore" as EventStore #LightGreen
participant "RabbitMQ\n(Wolverine Transport)" as MessageBroker #Orange
participant "Wolverine Handler\nInternship.Application" as InternshipHandler #LightBlue
participant "Wolverine Handler\nReporting.Application" as ReportingHandler #LightBlue
database "coordination schema" as DB

' Ziyaret programını görüntüleme
Teacher -> UI: Haftalık ziyaret programını aç
UI -> API: GET /api/coordination/schedule/{teacherId}
API -> Handler: Handle(GetVisitScheduleQuery)
Handler -> EventStore: session.LoadAsync<VisitSchedule>(id)
EventStore -> DB: SELECT (JSONB)
DB --> EventStore: VisitSchedule document
EventStore --> Handler: VisitSchedule
Handler --> API: VisitScheduleDTO
API --> UI: Ziyaret programı
UI --> Teacher: Günün ziyaret programı gösterilir

' Ziyaret raporu doldurma
Teacher -> UI: Ziyaret raporunu doldur
UI -> API: POST /api/coordination/visits
API -> Handler: Handle(CompleteVisit command)
Handler -> EventStore: session.Events.Append(streamId, VisitCompleted)
EventStore -> DB: INSERT event
DB --> EventStore: Success

' Cascading message
Handler --> API: VisitCompleted (cascading)
API --> UI: Success
UI --> Teacher: "Ziyaret raporu kaydedildi" mesajı

' Asenkron event dağıtımı
Handler -> MessageBroker: PublishAsync<VisitCompleted>
MessageBroker ->> InternshipHandler: Handle(VisitCompleted)
MessageBroker ->> ReportingHandler: Handle(VisitCompleted)

note right of Handler
  Wolverine Middleware Pipeline:
  - FluentValidation
  - AutoApplyTransactions (Marten)

  Hybrid Storage:
  - VisitSchedule → Document (Marten JSONB)
  - VisitReport → Event Sourcing
end note

@enduml
```

### Departman Dağıtım (DepartmentDistribution)

```plantuml
@startuml CDDSequenceDiagram
autonumber

actor "Alan Şefi" as DeptHead
actor "Müdür" as Principal
participant "Web UI" as UI
participant "MESNET.Coordination.Api\nCoordinationEndpoints" as API
participant "MESNET.Coordination.Application\nCreateDepartmentDistributionHandler" as CreateHandler #LightBlue
participant "MESNET.Coordination.Application\nCalculateWorkloadHandler" as WorkloadHandler #LightBlue
participant "MESNET.Coordination.Application\nApproveDepartmentDistributionHandler" as ApproveHandler #LightBlue
participant "Marten\nIDocumentSession" as DocSession #LightGreen
participant "Marten\nIEventStore" as EventStore #LightGreen
participant "RabbitMQ\n(Wolverine Transport)" as MessageBroker #Orange
participant "Wolverine Handler\nReporting.Application" as ReportingHandler #LightBlue
database "coordination schema" as DB

' 1. Alan şefi öğretmen ders programlarını ve boş saatleri görüntüler
DeptHead -> UI: Dağıtım ekranını aç
UI -> API: GET /api/coordination/schedule/{teacherId}
API -> DocSession: session.LoadAsync<TeacherSchedule>(teacherId)
DocSession -> DB: SELECT (JSONB)
DB --> DocSession: TeacherSchedule documents
DocSession --> API: Öğretmen ders programları
API --> UI: Öğretmenlerin boş saatleri listelenir
UI --> DeptHead: Boş saat tablosu gösterilir

' 2. İş yükü hesaplama
DeptHead -> UI: Öğretmen seçip iş yükü hesapla
UI -> API: GET /api/coordination/workload/{teacherId}
API -> WorkloadHandler: Handle(CalculateWorkload query)
WorkloadHandler -> DocSession: TeacherSchedule + WorkloadConfig yükle
DocSession -> DB: SELECT (JSONB)
DB --> DocSession: Schedule + Config
WorkloadHandler -> WorkloadHandler: Formül hesapla:\nKullanılabilir = Azami - ŞeflikIndirimi\nKullanılan = Σ(AtananSaatler)\nKalan = Kullanılabilir - Kullanılan
WorkloadHandler --> API: TeacherWorkloadCalculated
API --> UI: İş yükü sonuçları
UI --> DeptHead: Kullanılabilir/kullanılan/kalan saat gösterilir

' 3. Alan şefi atamaları yapar
DeptHead -> UI: İşletmeleri öğretmenlere dağıt
note right of UI
  Her atama için:
  - Mesafe kontrolü (MaxDistanceKm)
  - Ek ders sınırı kontrolü
  - Boş saat uyumu kontrolü
end note
UI -> UI: Client-side validasyon\n(mesafe, saat sınırı)

' 4. Zümre karar tutanağı eklenir
DeptHead -> UI: Zümre karar tutanağı notunu ekle
UI -> UI: CommitteeDecisionNotes alanı doldurulur

' 5. Dağıtım oluşturulur
DeptHead -> UI: Dağıtımı kaydet
UI -> API: POST /api/coordination/distributions
API -> CreateHandler: Handle(CreateDepartmentDistribution command)
CreateHandler -> CreateHandler: Validasyon:\n- Tüm atamalar ek ders sınırı içinde mi?\n- Mesafe limiti aşılıyor mu?\n- Boş saat uyumu var mı?
CreateHandler -> EventStore: session.Events.StartStream(DepartmentDistributionCreated)
EventStore -> DB: INSERT event
DB --> EventStore: Success
CreateHandler --> API: DepartmentDistributionCreated (cascading)
API --> UI: Success
UI --> DeptHead: "Dağıtım kaydedildi, müdür onayı bekleniyor"

' 6. Müdüre onay gönderilir
CreateHandler -> MessageBroker: PublishAsync<DepartmentDistributionCreated>

' 7. Müdür onay/red
Principal -> UI: Dağıtım onay ekranını aç
UI -> API: Dağıtım detaylarını getir
API --> UI: DepartmentDistribution + Assignments
UI --> Principal: Dağıtım detayları gösterilir

alt Müdür onaylarsa
    Principal -> UI: Onayla
    UI -> API: POST /api/coordination/distributions/approve
    API -> ApproveHandler: Handle(ApproveDepartmentDistribution command)
    ApproveHandler -> EventStore: session.Events.Append(streamId, DepartmentDistributionApprovedByPrincipal)
    EventStore -> DB: INSERT event
    DB --> EventStore: Success
    ApproveHandler --> API: DepartmentDistributionApprovedByPrincipal (cascading)
    API --> UI: Success
    UI --> Principal: "Dağıtım onaylandı"

    ' Asenkron event dağıtımı
    ApproveHandler -> MessageBroker: PublishAsync<DepartmentDistributionApprovedByPrincipal>
    MessageBroker ->> ReportingHandler: Handle(DepartmentDistributionApprovedByPrincipal)
else Müdür reddederse
    Principal -> UI: Reddet (gerekçe gir)
    UI -> API: POST /api/coordination/distributions/reject
    API -> EventStore: DepartmentDistributionRejected event
    EventStore -> DB: INSERT event
    API --> UI: Success
    UI --> Principal: "Dağıtım reddedildi"
end

note right of EventStore
  DepartmentDistribution Event Sourcing:
  - Tüm dağıtım kararları audit trail
  - Zümre karar tutanağı saklanır
  - Müdür onay/red gerekçesi saklanır
  - Status geçişleri: TASLAK → ZÜMRE_KARARI_ALINDI
    → MÜDÜR_ONAY_BEKLİYOR → ONAYLANDI/REDDEDİLDİ
end note

@enduml
```
